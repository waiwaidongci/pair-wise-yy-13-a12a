# hxyfront-62012 纺织染整小样送样确认台

染整实验室小样管理前端。小样页已升级为**送样确认台**：小样绑定订单 / 配方版本 / 色卡版本，称料与复核两人分别签名，按投料核算染料成本，余量不足或超预算即挂起，不能出送样单。

## 业务规则

- 每个小样绑定：客户订单、配方（含版本）、色卡（含版本）、投料布重。
- 双签：**称料确认**与**复核确认**必须由两人分别签名，同一人不能复核自己称的料。
- 成本：按投料布重 × 配方投染百分比计算各染料用量与金额，与订单剩余预算（预算 − 已占用）核对。
- 阻断：染料库存余量不足或成本超预算时，确认单停在「待处理」，无法进入复核、出具送样单；补库 / 调预算后需重新核对通过方可继续。
- 出样：双签齐备且出样前再次核对余量与预算通过，才生成送样单，并扣减染料库存、占用订单预算。
- 变更失效留档：配方升版、色卡升版、订单预算调整后，相关未出样的旧确认单置为「已失效」留档，小样自动指向新版本并生成新确认单，重新走称料 → 复核流程；已出样单不受影响。
- 列表支持按订单与状态筛选、按小样编号搜索；展开后核对成本明细、双签审批人与新旧版本差异（配方组分 / 色卡 Lab / 预算 / 投料 / 成本差额）。

## 分层结构（计算、档案、页面分开承载）

```
src/
├─ calc/                    # 计算层：纯函数，不依赖 React / 状态
│  ├─ types.ts              # 领域类型
│  ├─ cost.ts               # 投料用量、成本、余量/预算核对
│  └─ diff.ts               # 两版确认单差异对比
├─ archive/                 # 档案层：状态机、留档、审计
│  ├─ seed.ts               # 初始档案（染料/配方版本/色卡/订单/小样/确认单）
│  └─ store.ts              # 纯 reducer：双签、阻断、出样、升版失效重建
└─ pages/confirm-desk/      # 页面层
   ├─ ConfirmDesk.tsx       # 列表、筛选、指标、状态接入
   └─ components/           # 成本表、双签区、版本差异、留档、维护台、送样单
```
